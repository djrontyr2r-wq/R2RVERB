# R2RVERB — DJ R2R Music

Native 64-bit Windows VST3 reverb plugin project.

## Target
- Windows 10/11 x64
- VST3
- C++20 / JUCE 8
- Visual Studio 2022
- FL Studio and other VST3 hosts

## Reverb modes
- Hall
- Room
- Plate

## Main controls
Algorithm, Size, Decay, Pre-Delay, Damping, Width, Wet, Dry, Low Cut, High Cut, Freeze, Bypass.

## Build
This repository will contain the JUCE plugin source and CMake project. Build the VST3 target on Windows with Visual Studio 2022 and the JUCE VST3 SDK support enabled.
